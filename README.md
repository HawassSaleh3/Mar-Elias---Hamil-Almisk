# 🕌 حامل المسك — Mar Elias, Beirut

موقع إلكتروني فاخر **ثنائي اللغة (العربية RTL / English LTR)** (HTML + CSS + JavaScript خالص — بدون مكتبات خارجية سوى خطوط Google) لمحل عطور **«حامل المسك»** في **مار إلياس — بيروت**، مع **سلة تسوق** ترسل الطلب **عبر واتساب**. زر التبديل بين اللغتين في أعلى الموقع ويُحفظ اختيار الزائر.

## 🚀 التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## 🧩 بنية الملفات

```
├── index.html          # الصفحة الرئيسية (عربية RTL بالكامل)
├── css/style.css       # التصميم الفاخر (داكن + ذهبي)
├── js/i18n.js         # نظام اللغتين + زر التبديل
├── js/products.js      # بيانات العطور (عربي/إنجليزي) + إعدادات المتجر (رقم الواتساب…)
├── js/lebanon.js       # قوائم مناطق ومدن لبنان لقوائم التوصيل (المحافظات + البلدات)
├── js/main.js          # منطق الموقع: السلة، التصفية، واتساب، النوافذ
└── assets/
    ├── img/            # صور العطور (استوديو داكن موحّد)
    ├── favicon.svg
```

## ⚙️ التخصيص السريع

| ماذا تريد تغيير؟ | أين؟ |
|---|---|
| **رقم الواتساب** | `js/products.js` ← ثابت `SHOP_CONFIG.phone` (بالـ 961… بدون + أو صفر) |
| **إضافة/تعديل/حذف عطور** | `js/products.js` ← مصفوفة `PRODUCTS` (الاسم، الفئة، الصورة، سعر 50 و100 مل…) |
| **الأسعار** | `price50` و `price100` داخل كل منتج (الموقع يعرضها بالدولار `$`) |
| **رسوم/حد التوصيل المجاني** | `SHOP_CONFIG.deliveryFee` و `freeDeliveryOver` |
| **الألوان العامة** | `css/style.css` ← متغيرات `:root` |
| **ساعات الدوام/العنوان/الوصف** | في `index.html` (أقسام التواصل والتذييل) |
| **صور العطور** | ضع صورك في `assets/img/` بنفس الأسماء أو غيّر `img` لكل منتج |

## ✨ المزايا

- تصميم فاخر داكن بذهبي شرقي مستوحى من أرقى مواقع العطور (Chanel / Dior / Byredo / العربية للعود)
- عربي كامل RTL + إنجليزي كامل LTR مع زر تبديل فوري (يُحفظ تلقائياً) وخطوط فاخرة لكل لغة
- سلة تسوق جانبية (تخزين محلي localStorage) مع اختيار **الحجم 50/100 مل** والكمية
- **إتمام الطلب في 3 خطوات داخل السلة:** (1) مراجعة العناصر ← (2) بيانات العميل (الاسم، الهاتف، المنطقة والمحافظة، المدينة/البلدة من **قوائم منسدلة لكل لبنان**، العنوان بالتفصيل، الملاحظات) ← (3) إرسال عبر واتساب
- **رسالة واتساب منسّقة ومرتّبة** تتضمن كل التفاصيل: العناصر والكميات والأسعار والمجموع + بيانات العميل والعنوان والملاحظات
- التحقق من بيانات العميل (رقم الهاتف اللبناني والحقول المطلوبة) قبل إرسال الطلب
- تصفية حسب المجموعة + بحث + ترتيب حسب السعر
- نافذة عرض سريع لكل عطر
- أزرار استفسار واتساب لكل منتج + زر واتساب عائم
- شاشة تحميل، حركات ظهور عند التمرير، تصميم متجاوب كامل للجوال
- تحسينات SEO أساسية (وصف، alt، favicon)
